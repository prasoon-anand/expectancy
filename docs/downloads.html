Installation notes

Verify the packageInstall safelyUpdating the appAfter installation

Verify before opening.

  1. 1
    Match the platform and architecture

    The first release is for Apple Silicon, not Intel Macs. Check the chip in About This Mac, then compare your macOS version with the exact release’s tested requirements. Do not infer compatibility from the processor alone.

  2. 2
    Compare the SHA-256 checksum

    Calculate the digest of your downloaded file and compare it with the release’s checksum record. A checksum detects file changes; it does not identify the publisher by itself.

  3. 3
    Check publisher verification

    Read the release’s signing or notarization status. Do not assume a package is signed because it appears on this page.

Check the SHA-256 checksum on macOS

In Terminal, replace the quoted filename with the exact path to your downloaded disk image. Compare the output with the checksum in that release’s record.

shasum -a 256 "Expectancy.dmg"

This checks the file’s digest, not its signing identity or notarization status.

Follow the package’s instructions.

Use the installation steps attached to the specific release. Package formats, runtime dependencies and minimum system versions may differ. If your system reports an unknown publisher or failed signature, stop and verify the release record; do not disable operating-system protections to continue.

Your data is separate from the installer

Expectancy does not supply market data. Import your own files or begin with the synthetic tutorial dataset. Check data rights before sharing projects or exported results.

Preserve your research when updating.

Export important datasets, strategies and completed evidence before replacing an installed version. Read migration notes for storage or schema changes. Keep the previous installer until you have verified that your saved work opens correctly; do not assume an older version can read newer storage.
